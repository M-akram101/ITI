# Sorting Algorithms Comparison

## QuickSort vs Other Sorting Algorithms

### 1. QuickSort
```python
# Time: O(n log n) average, O(n²) worst
# Space: O(log n)
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[-1]
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)
```

### 2. MergeSort
```python
# Time: O(n log n) always
# Space: O(n)
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
```

### 3. HeapSort
```python
# Time: O(n log n) always
# Space: O(1)
def heap_sort(arr):
    def heapify(arr, n, i):
        largest = i
        left = 2 * i + 1
        right = 2 * i + 2
        if left < n and arr[left] > arr[largest]:
            largest = left
        if right < n and arr[right] > arr[largest]:
            largest = right
        if largest != i:
            arr[i], arr[largest] = arr[largest], arr[i]
            heapify(arr, n, largest)
    
    n = len(arr)
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    for i in range(n-1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
    return arr
```

### 4. Python's Built-in Sort (Timsort)
```python
# Time: O(n log n) worst case
# Space: O(n)
sorted_array = sorted(arr)  # Creates new sorted list
arr.sort()  # In-place sorting
```

## Comparison Table

| Algorithm | Time (Average) | Time (Worst) | Space | Stable | In-Place |
|-----------|---------------|--------------|-------|---------|----------|
| QuickSort | O(n log n) | O(n²) | O(log n) | No | Yes* |
| MergeSort | O(n log n) | O(n log n) | O(n) | Yes | No |
| HeapSort | O(n log n) | O(n log n) | O(1) | No | Yes |
| Timsort | O(n log n) | O(n log n) | O(n) | Yes | No |

## Key Differences

1. **Stability**
   - MergeSort and Timsort maintain relative order of equal elements
   - QuickSort and HeapSort don't guarantee stability

2. **Memory Usage**
   - HeapSort is truly in-place
   - MergeSort requires O(n) extra space
   - QuickSort uses O(log n) stack space
   - Timsort needs O(n) temporary storage

3. **Performance Characteristics**
   - QuickSort: Best for random data
   - MergeSort: Best for linked lists
   - HeapSort: Best when memory is constrained
   - Timsort: Best for partially sorted data

4. **Best Use Cases**
   - QuickSort: Random access data, general purpose
   - MergeSort: Stable sorting, external sorting
   - HeapSort: Memory-constrained systems
   - Timsort: Real-world data with patterns

## Python's Choice
Python uses Timsort (hybrid of MergeSort and insertion sort) because:
- Stable sorting
- Adaptive to real-world data patterns
- Excellent performance on partially sorted arrays
- Maintains merge order for equal elements
